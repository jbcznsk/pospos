# 💡 Repositório de Ideias para TCC (Ciência de Dados & IA)

Bem-vindo(a) ao repositório! Este espaço foi criado para organizar e centralizar diferentes propostas de temas para Trabalho de Conclusão de Curso (TCC), unindo a área de Ciência de Dados e Inteligência Artificial a diferentes domínios do conhecimento.

## 🔀 Organização do Repositório (Branches)

Para manter o projeto limpo e facilitar a navegação, **cada branch deste repositório corresponde a uma lista temática exclusiva de ideias para TCC**. 

Em vez de misturar todos os temas em um único arquivo, você pode navegar pelas ramificações do Git para focar na área que mais te interessa. As seguintes divisões estão disponíveis:

*   **`main` / `master`**: Contém este texto explicativo e as instruções gerais de navegação.
*   **`tcc/plantas`**: Lista com propostas voltadas para o reino vegetal, botânica, agricultura de precisão e IoT na lavoura.
*   **`tcc/bichos`**: Lista com temas aplicados ao reino animal, abrangendo cuidados com pets, pecuária inteligente e conservação da fauna silvestre.

## 📌 Evolução do Projeto (Futuro da Branch Main)

Este formato de múltiplas branches serve apenas para a **fase inicial de brainstorm e escolha do tema**. 

Assim que um tema definitivo for selecionado para o TCC, este repositório mudará de foco:
1. As branches de ideias serão mantidas apenas como histórico.
2. A branch **`main` passará a conter exclusivamente o projeto escolhido** (código-fonte, notebooks, documentação e o artigo/monografia final).

Portanto, no futuro, este texto explicativo será substituído pelo README oficial do TCC desenvolvido.

## 🛠️ Como navegar entre as listas atuais

Você pode alternar entre as opções de temas de duas formas:

1.  **Pela interface do GitHub/GitLab:** Clique no menu do canto superior esquerdo (onde diz `main`) e selecione a branch com a temática desejada. O arquivo `README.md` mudará automaticamente para a lista correspondente.
2.  **Pelo terminal (Git CLI):** Caso tenha clonado o repositório, utilize o comando para mudar de branch:
    ```bash
    git checkout nome-da-branch
    # Exemplo: git checkout tcc/bichos
    ```
